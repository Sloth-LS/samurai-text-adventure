The Samurai Who Lost His Sword 🗡️
A funny text adventure made in Python.

You are Takeshi, the most feared samurai in Japan (says you). Tomorrow you fight your rival Kenji the Slightly Better. There is just one problem... you lost your sword. Again.

How to play
You need Python installed. Then run:

python the-lost-samurai-sword.py
Type commands like go north, take rice ball, talk and help.

Endings
There are 3 endings. Can you find them all?
